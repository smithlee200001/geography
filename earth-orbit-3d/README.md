# 地球公转 · 3D 探索

独立的中文地理教学演示，专注于地球绕太阳公转及四季成因。与相邻的 `earth-motion-3d` 演示互不依赖。

## 运行

直接用现代浏览器打开 `index.html` 即可。无安装步骤、无第三方依赖、无 CDN，离线可用。

- 拖动画面或聚焦画布后按方向键旋转三维视角。
- 使用立体、北极上空、侧面视角预设。
- 播放/暂停、调整速度、拖动时间轴或跳转四个季节节点。
- 四季位置上的平行地轴帮助观察其全年近似不变的指向。
- 默认暂停，适合课堂讲解和减少不必要的动画。

## 模型边界

Canvas 使用三维世界坐标、相机投影和深度排序，不是预录视频。当前地球逐像素计算受光，地轴相对公转轨道法线倾斜 23.4°。四季以北半球为主，南半球相反。公转从北极上空观察为逆时针。

圆形轨道是教学简化，透视下显示为椭圆；真实轨道略有偏心。地球、太阳尺寸与距离不按真实比例。时间轴从冬至起按 365.25 天演示，四季位置等分，不用于精确历法或节气计算。地球贴图是示意大陆轮廓，不是地图数据。本演示不加速展示自转。四季主要由地轴倾斜导致，而不是地日距离变化。

参考：[NASA 地球资料](https://science.nasa.gov/earth/facts/)；[NASA 四季说明](https://spaceplace.nasa.gov/seasons/en/)。

## 验证

需要 Node.js 18 或更新版本，仅用于测试，不是运行依赖：

```sh
node --check app.js
node --test model.test.cjs
```

测试覆盖轨道闭合、半径、轨道平面、轴向归一化、四季受光和运动方向。浏览器视觉与移动端交互需单独检查。
